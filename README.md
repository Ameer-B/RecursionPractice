# Sierpinski Carpet (C#)

A simple implementation of the **Sierpinski Carpet**, a classic fractal generated by repeatedly subdividing a square and removing its center. This project focuses on the recursive logic behind fractal construction and provides a clear, minimal visual output.

---

## Concept
The Sierpinski Carpet is built using recursion:

1. Start with a square  
2. Divide it into a 3×3 grid  
3. Remove the center square  
4. Repeat the process for each remaining square

This creates a self‑similar fractal pattern that becomes more detailed with each recursion level.

---

## Purpose
A small project created to practice recursion, fractal generation, and simple graphical rendering. The goal is to demonstrate how complex patterns can emerge from straightforward recursive rules.
